# Bilaga B – Självvärdering: vilket är ditt nästa steg?

Det här är inte ett test och ger inget mognadspoäng. Syftet är att hjälpa dig identifiera **ett konkret nästa experiment** i ditt eget arbete.

Gör gärna självbedömningen för ett arbetsområde i taget, exempelvis kravarbete, arkitektur, implementation, test, felsökning eller dokumentation. Du kan vara långt framme inom ett område och arbeta betydligt enklare med AI inom ett annat.

## 1. Kartlägg din repertoar

Markera de arbetsformer som du faktiskt använder återkommande i verkligt arbete, inte bara sådant du har provat en gång.

| Arbetsform | Gör jag detta återkommande? | Exempel från mitt arbete |
|---|---|---|
| **Fråga** – använder AI för information och förklaringar | ☐ | |
| **Resonera** – jämför alternativ, testar hypoteser och söker motargument | ☐ | |
| **Skapa** – låter AI skapa konkreta arbetsobjekt | ☐ | |
| **Samarbeta** – itererar över samma problem eller artefakt i flera varv | ☐ | |
| **Ge kontext** – arbetar med verkliga filer, repositoryn, modeller eller andra lokala underlag | ☐ | |
| **Delegera** – ger AI ett sammanhängande mål med definierade ramar | ☐ | |
| **Orkestrera** – använder AI i ett återkommande flerledat arbetsflöde | ☐ | |

Fråga dig sedan:

- Vilken arbetsform använder jag mest?
- Vilken använder jag nästan aldrig?
- Finns det en arbetsform ett steg utanför min nuvarande vana som skulle lösa ett verkligt problem?
- Finns det arbetsformer jag medvetet **inte** bör använda för vissa uppgifter?

## 2. Bedöm situationsanpassningen

Mogen AI-användning innebär inte bara större repertoar. Den innebär att du ändrar arbetsform efter uppgiftens egenskaper.

Fundera på ett par konkreta situationer från den senaste tiden.

### Jag väljer arbetssätt efter risk

- ☐ Jag skiljer mellan reversibla och irreversibla konsekvenser.
- ☐ Jag ger AI mindre handlingsutrymme när konsekvenserna är svåra att återställa.
- ☐ Jag höjer verifieringsnivån när fel kan få stora konsekvenser.

### Jag väljer arbetssätt efter osäkerhet

- ☐ Jag använder AI för att synliggöra antaganden och informationsluckor.
- ☐ Jag skiljer mellan frågor med tydligt facit och frågor som kräver omdöme.
- ☐ Jag kan stanna i resonemangsfasen när ett beslut ännu inte bör automatiseras.

### Jag väljer arbetssätt efter information

- ☐ Jag bedömer vilken kontext som faktiskt behövs.
- ☐ Jag tänker på vad själva prompten avslöjar, inte bara på bifogade filer.
- ☐ Jag vet vilken AI-miljö och vilka regler som gäller för icke-publikt material.

### Jag väljer arbetssätt efter lärandemål

- ☐ Jag skiljer mellan när målet är snabb leverans och när målet är att själv lära mig.
- ☐ Jag kan använda AI som träningspartner i stället för facit när egen färdighet behöver byggas.

Om flera rutor känns osäkra är nästa steg kanske inte mer avancerad AI-användning. Det kan vara att bli bättre på **valet av arbetsform**.

## 3. Bedöm din kontroll

Kontroll handlar om att kunna avgöra om resultatet är tillräckligt bra och om AI:n har fått rimligt handlingsutrymme.

### Resultatkontroll

- ☐ Jag definierar vad som ska vara sant när uppgiften är klar.
- ☐ Jag skiljer ett plausibelt resultat från ett verifierat resultat.
- ☐ Jag använder exekverbara kontroller där det går: tester, validering, linting, statisk analys eller andra mekaniska kontroller.
- ☐ Jag vet när mänsklig eller oberoende granskning behövs utöver AI:ns egen kontroll.

### Kontextkontroll

- ☐ Jag kan bedöma om AI arbetar med rätt och aktuellt underlag.
- ☐ Jag vet vilka källor eller filer som faktiskt påverkat resultatet när det är viktigt.
- ☐ Jag reagerar när kontexten är motsägelsefull, föråldrad eller ofullständig.

### Handlingskontroll

- ☐ Jag ger AI minsta rimliga behörighet för uppgiften.
- ☐ Jag vet vilka verktyg agenten får använda och vad de kan förändra.
- ☐ Jag placerar kontrollpunkter före riskfyllda eller irreversibla steg.

### Systemkontroll

- ☐ Jag mäter inte bara om ett lokalt moment går snabbare, utan också vad som händer med review, test, köer och kvalitet längre fram.
- ☐ Jag kan upptäcka när ett AI-arbetssätt som tidigare fungerade börjar ge sämre resultat.

## 5. Utvärdera efteråt

Efter experimentet, ställ fem frågor:

1. Blev resultatet bättre, snabbare eller på annat sätt mer värdefullt?
2. Flyttades arbete eller problem bara till review, test eller ett senare steg?
3. Vilken del av AI:s bidrag gav mest värde?
4. Var behövdes mer mänskligt omdöme eller kontroll än väntat?
5. Bör arbetssättet upprepas, justeras, förenklas eller överges?

Det sista alternativet är viktigt. Ett moget experiment kan sluta med slutsatsen att AI **inte** bör användas på det sättet för just den uppgiften.

## En enkel tumregel

Om du vill ta dig vidare i mognadsresan behöver du inte fråga:

> Hur kan jag använda mer AI?

En bättre fråga är:

> **Vilken del av mitt arbete skulle vinna på en annan arbetsfördelning mellan mig, AI och automation – och hur kan jag prova det utan att förlora kontrollen?**
