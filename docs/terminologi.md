# Terminologi

## Styrande termer

### AI-assistent

Övergripande term för en generativ AI-tjänst som användaren interagerar med för kunskapsarbete. Används när produkten i sig inte är viktig.

### Generativ AI

Används för teknikområdet. Undvik att använda "AI" som om alla typer av artificiell intelligens vore samma sak när skillnaden är relevant.

### AI-assisterat arbete

Arbete där AI bidrar men där människans mål, ansvar och bedömning fortfarande är centrala. Föredras framför formuleringar som antyder full automation när det inte är vad som avses.

### Mognadsresa

Den utveckling av arbetssätt som boken beskriver. Mognad betyder bättre förmåga att välja och styra AI-användningen, inte högsta möjliga autonomi.

### Kontext

Det material och de förutsättningar AI:n behöver för att förstå den aktuella uppgiften: instruktioner, filer, repository, modeller, historik, mål, begränsningar med mera.

### Delegera

Att ge AI ansvar för att genomföra en sammanhängande arbetsuppgift inom definierade ramar. Ska skiljas från att delegera ansvar i organisatorisk eller juridisk mening.

### Orkestrera

Att utforma ett arbetsflöde där AI, människor, verktyg, information och kontrollpunkter samverkar över flera steg.

### Agent / agentiskt arbetssätt

Använd sparsamt och definiera första gången. Avser system som kan planera och utföra flera steg och använda verktyg för att nå ett mål. Undvik att använda "agent" som marknadsföringsetikett när vanlig assistentfunktionalitet räcker som beskrivning.

## Produktnamn

ChatGPT, Claude, Gemini, GitHub Copilot och Microsoft Copilot används endast när ett konkret produktexempel eller leverantörsspecifikt förhållande behövs.
